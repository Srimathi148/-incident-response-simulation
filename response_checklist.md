# Incident Response Checklist

## 1. Preparation
- [ ] Establish an incident response team.
- [ ] Prepare an incident response plan.
- [ ] Maintain regular data backups.
- [ ] Train employees to identify phishing emails.

## 2. Detection and Analysis
- [ ] Identify suspicious emails and login activities.
- [ ] Review security logs.
- [ ] Identify affected accounts and systems.
- [ ] Determine the severity of the incident.
- [ ] Record all important evidence.

## 3. Containment
- [ ] Restrict the compromised account.
- [ ] Revoke active login sessions.
- [ ] Block suspicious email addresses and links.
- [ ] Isolate affected devices when necessary.
- [ ] Prevent further unauthorised access.

## 4. Eradication
- [ ] Remove unauthorised mailbox rules.
- [ ] Reset compromised passwords.
- [ ] Remove identified malicious files or activity.
- [ ] Fix security vulnerabilities.
- [ ] Verify that the threat has been removed.

## 5. Recovery
- [ ] Restore files from verified backups.
- [ ] Check system functionality.
- [ ] Reconnect systems safely.
- [ ] Monitor systems for suspicious activity.
- [ ] Confirm that normal operations have resumed.

## 6. Post-Incident Review
- [ ] Document the incident.
- [ ] Identify security weaknesses.
- [ ] Review the response team's performance.
- [ ] Recommend security improvements.
- [ ] Conduct employee awareness training.

**Note:** This checklist is designed for a fictional educational incident response simulation.
