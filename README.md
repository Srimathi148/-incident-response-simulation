# Incident Response Simulation

## Project Overview
This project demonstrates a simulated cybersecurity incident and explains how an organisation can identify, analyse, contain, eradicate, and recover from a security attack.

## Incident Scenario
A fictional employee receives a phishing email containing a fake document-sharing link. The employee enters their login credentials and approves an unexpected multi-factor authentication request. An attacker gains unauthorised access to the employee's account. Suspicious login activity, unusual mailbox changes, and unexpected file modifications are subsequently detected.

## Objectives
- Understand cybersecurity incident response.
- Identify phishing and account compromise indicators.
- Analyse security risks and potential impact.
- Apply incident response stages.
- Recommend preventive security measures.

## Incident Response Stages
1. Detection and Analysis
2. Containment
3. Eradication
4. Recovery
5. Post-Incident Review

## Tools and Approach
This is a documentation-based tabletop simulation. It uses a fictional scenario, incident timeline, risk assessment, and response checklist. No real systems or credentials are used.

## Expected Outcome
The project demonstrates how a structured incident response process can reduce security risks, minimise damage, and improve organisational cybersecurity preparedness.
