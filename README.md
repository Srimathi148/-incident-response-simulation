# Cybersecurity Incident Response Simulation

## Project Overview

This project presents a structured cybersecurity incident response simulation based on a phishing-based account compromise followed by suspected ransomware-related activity.

The simulation is designed around a fictional IT organisation, Apex Technologies Pvt. Ltd., to demonstrate how a cybersecurity team identifies, investigates, contains, eradicates and recovers from a security incident.

## Objectives

- Understand how phishing attacks can lead to credential compromise.
- Identify suspicious account activity and unauthorised access.
- Simulate the five major incident response stages.
- Prepare a chronological incident timeline.
- Assess security risks and potential organisational impact.
- Document lessons learned and recommend preventive measures.

## Simulated Incident Scenario

An employee receives a fraudulent IT-related email requesting account verification. The employee enters their credentials on a fake login page. An attacker subsequently uses the compromised credentials to access the employee's account, creates an unauthorised email-forwarding rule and attempts to access internal company files.

The security team detects unusual login activity and suspicious file modifications, prompting an incident response investigation.

**Note:** This is a fictional, documentation-based simulation. All organisation details, events, alerts and evidence records are hypothetical.

## Incident Response Stages

1. Detection
2. Analysis
3. Containment
4. Eradication
5. Recovery
